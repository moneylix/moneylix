Project Overview
What Moneylix is and who it's for

Moneylix is a full-stack SaaS finance management application built for Indian freelancers, creators, and small businesses. It allows users to track income and expenses, manage receivables, view analytics, and get AI-powered investment advice — available on Web, iOS, and Android.

Key Objectives

ObjectiveDescription
Income & Expense TrackingLog all transactions with categories, notes, tags, and payment method
Multi-Business SupportSwitch between multiple businesses with fully isolated data
Receivables ManagementTrack pending client payments with due-date reminders
AI Investment AdvisorClaude AI gives personalized investment suggestions (SIP, Gold, FD)
Analytics DashboardCash flow charts, spending split, savings rate
Plan-Based AccessFree / Pro / Premium tiers with Razorpay payments
Mobile AppNative iOS and Android app via Capacitor WebView
Admin PanelFull admin control of users, plans, and platform stats

Target Users

  • Freelancers — designers, developers, consultants
  • Small business owners
  • Creators and solopreneurs in India

Features by Page
What each page does

Dashboard — Main

  • Welcome panel: business name, quick search, export button, add transaction
  • 4 stat cards: Total Balance, Monthly Income, Monthly Expense, Savings Rate (equal height)
  • Cash flow bar chart (last 7 or 30 days toggle)
  • Spending split donut chart with category breakdown
  • Recent transactions as compact cards (mobile) or table (desktop)

Transactions

  • Full list with search, filter (type, category, date range), sort, pagination (20 per page)
  • Add / Edit / Delete via slide-up modal
  • Bulk select → bulk delete or bulk category change
  • Export as CSV or JSON download
  • Import from CSV (bulk create)
  • OCR receipt scanner via Tesseract.js (Premium plan only)
  • Mobile: compact card list — date, note, category, method, amount, edit/delete
  • Desktop: full table with all columns

Bank Sync — Pro & Premium

  • Connect bank accounts via Setu Account Aggregator (RBI-regulated consent flow)
  • BankSyncCard shows connection status, masked account number, last sync time
  • Manual "Sync now" trigger with sync progress polling
  • Fetched transactions list with AI-suggested categories and confidence scores
  • Confirm/edit category, link to existing manual transaction, or ignore/flag duplicate
  • /dashboard/bank/status handles the redirect back from Setu consent approval
  • All consent and data-fetch events written to the RBI compliance audit trail

Recurring Transactions

  • Create scheduled transaction templates — daily, weekly, monthly, or yearly with custom interval
  • Set start date, optional end date, and day-of-week / day-of-month / month-of-year rules
  • Pause, resume, edit, or delete a schedule
  • Shows next run date and total transactions generated so far
  • Background cron (/api/cron/process-recurring) auto-creates due transactions

Profile

  • View and edit display name and email
  • Change password
  • Permanently delete account and all associated data, with confirmation

AI Advisor

  • Powered by Anthropic Claude API
  • Natural language financial questions
  • Investment recommendations: SIP, Digital Gold, PPF, FD
  • Personalized based on user income and savings
  • Premium plan required for full access

Admin Panel

  • Platform KPIs: total users, revenue, transactions, pending features
  • Plan distribution: Free / Pro / Premium user counts
  • Renewal alerts: subscriptions expiring in next 7 days
  • Recent user registrations table
  • Change admin password widget (bcrypt)
  • User management: view, edit, deactivate
  • Broadcast messaging to all users

Native Detection Logic

const cap = (window as any).Capacitor
const isNative = cap?.isNativePlatform?.()

// Landing page: skip marketing, go to login
if (isNative) {
  const isLoggedIn = !!localStorage.getItem('moneylix_auth')
  window.location.replace(isLoggedIn ? '/dashboard' : '/auth/login')
}
